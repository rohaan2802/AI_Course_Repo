## Course Overview

Artificial Intelligence (AL2002) at FAST-NUCES Islamabad. The repository has the lecture slides, three Python assignments (multi-robot path planning, a genetic algorithm and an expectiminimax game), the final project brief, quiz and exam solutions, the lab notebooks from two batches, the textbook and my study notes.

## Topics Covered

| Unit | Topics |
|---|---|
| **Unit 1 – Agents and search** | Intelligent agents and environments, uninformed search (BFS, DFS, UCS, IDDFS) and informed search (greedy, A*). |
| **Unit 2 – Optimisation and constraints** | Local search and hill climbing, genetic algorithms, constraint satisfaction and cryptarithmetic. |
| **Unit 3 – Games** | Adversarial search, minimax, alpha-beta pruning and expectiminimax with chance nodes. |
| **Unit 4 – Machine learning** | Regression and gradient descent, KNN, decision trees, K-means clustering, perceptrons and neural networks. |

## Using the Files

```bash
git clone https://github.com/rohaan2802/AI_Course_Repo.git
cd AI_Course_Repo
pip install numpy pandas matplotlib seaborn scikit-learn jupyter
cd "AI Course/Assignments/A #01/A_22I-2327_Mohammad Rohaan" && python Assignment1.py
jupyter notebook   # open any lab notebook
```

- Lectures, assignment papers, reports and solutions are PDF and Word (`.docx`) files.
- Assignment code is Python 3; A#03 has a Tkinter GUI. Lab work is Jupyter notebooks (NumPy, Pandas, Matplotlib, scikit-learn) with the CSV datasets next to them.
- The study notes in `AI Course/Notes` are Markdown and read directly on GitHub. Some zipped notes and quiz material are kept as `.zip` files.
- You can also download everything as a ZIP from the Live Links table.
